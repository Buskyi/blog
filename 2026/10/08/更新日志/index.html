3. 增加 LaTeX 公式渲染

安装 hexo-filter-mathjax 插件，支持文章内 $$ 包裹的 LaTeX 公式渲染。 小笔记：

  1. 公式内部换行要写 \\\\，只写 \\ 会被 Markdown 提前转义，公式识别不到换行。
  2. LaTeX 公式里，*、_ 有特殊含义：_ 默认代表下标；* 不是普通星号，原样写会出问题，想要展示普通星号要用 \ast。

4. PJAX 跳转背景反复闪烁

最开始的写法，body 和 .paper 同时都挂载了背景图。A4 主题用 PJAX，页面切换只会刷新 body 内部 DOM，每次跳转都会重绘这两个元素的背景，页面切换时背景会闪动。

原 imageShow.ejs（旧，双背景）

修改后（背景移至 html 根元素）

解决方案：把背景直接放到 <html> 根标签上。html 不在 PJAX 重绘范围内，切换页面不会重新绘制背景。可选优化：添加 transform: translateZ(0) 开启 GPU 加速渲染。

5. 滚动条造成背景左右抖动

页面内容较短时，浏览器会自动隐藏垂直滚动条，页面可视宽度发生变化，居中的背景图就会出现左右偏移抖动。

在上一段修改后的 html 样式基础上增加一行：overflow-y: scroll;

解决方案：给 html 设置 overflow-y: scroll;，强制垂直滚动条一直存在，锁定页面视口宽度，消除背景的平移抖动。

6. 背景跟随 DarkReader 暗色模式同步变暗

DarkReader 只会反转页面文字颜色，不会处理背景图片。开启暗色模式后文字变成暗色，但背景还是亮图，视觉上很割裂。

最终完整版（在第 5 节代码基础上增加遮罩相关 CSS）

解决方案：用 body::before 生成一层遮罩层，设置 z-index:-1 放在所有页面内容底层。DarkReader 启动时会自动给 html 添加 data-darkreader-mode="dynamic" 属性，CSS 捕获这个属性，把遮罩改成半透明黑色。只压暗背景，不会干扰 DarkReader 处理文字。搭配 transition，明暗切换有平滑过渡效果。
